## Resumo
Exemplo de variáveis de ambiente para configurar os serviços Ollama e OpenRouter.

## Funcionamento
Define URLs opcionais, usadas quando não há valores personalizados, e chaves de API; a chave do OpenRouter é necessária para esse adaptador.

## Importações
- `OLLAMA_WEB_URL`: URL opcional da API Ollama.
- `OLLAMA_API_KEY`: Chave opcional da API Ollama.
- `OPENROUTER_URL`: URL opcional da API OpenRouter.
- `OPENROUTER_API_KEY`: Chave necessária para o adaptador OpenRouter.
