## Summary
Example environment variables for configuring the Ollama and OpenRouter services.

## Behavior
Defines optional URLs used when no custom values are provided and API keys; the OpenRouter key is required for that adapter.

## Imports
- `OLLAMA_WEB_URL`: Optional Ollama API URL.
- `OLLAMA_API_KEY`: Optional Ollama API key.
- `OPENROUTER_URL`: Optional OpenRouter API URL.
- `OPENROUTER_API_KEY`: Required key for the OpenRouter adapter.
