## Summary
Groups the HTTP behavior test modules.

## Behavior
Declares seven modules and associates each with its corresponding test file.

## Imports
- `enforces_agent_delete_permissions`: Tests permissions for agent file deletion.
- `handles_agent_edits`: Tests agent edits.
- `handles_agent_requests`: Tests agent requests.
- `handles_git_add_requests`: Tests Git add requests.
- `handles_git_status_requests`: Tests Git status requests.
- `preserves_literal_template_input`: Tests preservation of literal input.
- `rejects_invalid_requests`: Tests rejection of invalid requests.
