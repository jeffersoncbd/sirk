## Resumo
O arquivo declara dois módulos de testes RPC.

## Funcionamento
Inclui os módulos que testam solicitações de agentes e rejeição de métodos desconhecidos; não define uma função principal.

## Importações
- `tests/handles_agent_requests.rs`: Testes de solicitações de agentes.
- `tests/rejects_unknown_methods.rs`: Testes de métodos desconhecidos.
