## Resumo
Define o pacote Rust `sirk-sdk` para o protocolo JSON-RPC S.I.R.K.

## Funcionamento
Configura nome, versão, edição e descrição do pacote, além de declarar dependências para serialização, JSON e erros.

## Importações
- `serde`: Derivação de suporte à serialização.
- `serde_json`: Manipulação de dados JSON.
- `thiserror`: Definição de erros.
