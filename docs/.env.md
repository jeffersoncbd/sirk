## Resumo
Define o modelo de variáveis de ambiente para o template do Ollama (web e API key opcionais).

## Funcionamento
Serve como arquivo de exemplo (não é lido em runtime) para documentar quais variáveis o processo deve receber via `dotenv`. Todas possuem valor vazio por padrão: `OLLAMA_WEB_URL` e `OLLAMA_API_KEY` são opcionais e caem em defaults internos (URL `https://ollama.com/api` e nenhuma autenticação, respectivamente), enquanto `OPENROUTER_URL` também é opcional com default `https://openrouter.ai/api/v1/chat/completions`. Já `OPENROUTER_API_KEY` é marcada como obrigatória, pois o adaptador do OpenRouter sempre exige credencial — se ausente, a configuração falha na inicialização. Como as atribuições usam strings vazias (e não `VAR=`)... valores em branco são tratados como não definidos pelos carregadores usuais. Linhas em branco separam o bloco do Ollama do bloco do OpenRouter apenas para legibilidade.

## Importações
- Nenhuma: arquivo de configuração estática, sem dependências de código.
