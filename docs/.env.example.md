## Summary
Example environment variables for configuring Ollama, OpenRouter, and NVIDIA API access.

## Behavior
Lists optional service URLs and API keys, with comments indicating which adapter requires each key.

## Imports
- `OLLAMA_WEB_URL`: Optional Ollama API URL.
- `OLLAMA_API_KEY`: Optional Ollama API key.
- `OPENROUTER_URL`: Optional OpenRouter API URL.
- `OPENROUTER_API_KEY`: Required by the OpenRouter adapter.
- `NVIDIA_API_KEY`: Required by the NVIDIA API adapter.
