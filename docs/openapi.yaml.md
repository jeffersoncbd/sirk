## Summary
Defines the S.I.R.K. HTTP API, including agent execution, Git operations, health checks, and documentation routes.

## Behavior
Documents each route’s method, request and response formats, and possible errors. Agent input is passed literally; Git operations are scoped to the supplied directory. The specification also describes server binding and the lack of authentication or TLS.

## Imports
- None: this is an OpenAPI YAML document.
