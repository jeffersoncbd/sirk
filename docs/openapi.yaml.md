## Summary
Defines the S.I.R.K. HTTP API, including its endpoints, request and response schemas, and server details.

## Behavior
Documents health and API-specification access, agent execution, flow creation, Git staging and status, and file listing. It specifies request validation, flow ID requirements, success and error responses, and that directory paths are interpreted by the server. The service has no authentication or TLS.
